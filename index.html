Upload a CSV, Excel (.xlsx/.xls) or JSON file with container dispatch data — container, size, type, eir, dateOut, receivingParty, releaseOrderNo, vessel, voyage, truck, driver, origin, destination, remarks, work type, and distance. Only container is required; this is meant for migrating historical dispatch records too, so rows can be as complete or as sparse as the source data allows and won't be sent through any document verification step. If a container from this file was already imported earlier (e.g. a first batch had no truck/driver/destination yet), a later upload for the same container fills in whatever's still missing instead of creating a duplicate — see the checkbox below.

Bulk Inward Container Upload
Upload a CSV, Excel (.xlsx/.xls) or JSON file of inward containers.
